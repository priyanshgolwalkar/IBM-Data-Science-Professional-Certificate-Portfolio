# Databases and SQL for Data Science

## Overview

This module demonstrates structured querying of relational databases using SQL.

---

## Key SQL Concepts Covered

- SELECT statements
- WHERE filtering
- GROUP BY aggregation
- HAVING clause
- JOIN operations
- Aggregate functions (COUNT, SUM, AVG)

---

## Example Scenario

A student performance database was created to demonstrate querying, filtering, and aggregating structured data.

All example queries are available in the `queries.sql` file.
