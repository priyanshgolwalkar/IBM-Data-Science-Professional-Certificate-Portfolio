## 🚀 Featured Project: SpaceX Falcon 9 Landing Prediction

This capstone project demonstrates an end-to-end machine learning workflow:

- Data preprocessing  
- Exploratory data analysis  
- Feature engineering  
- Model training  
- Model evaluation using accuracy and confusion matrix  

**Model Used:** Random Forest Classifier  
**Objective:** Predict first-stage landing success using historical launch data.
